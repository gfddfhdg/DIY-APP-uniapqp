# DIY同城门户分类信息发布求职招聘房产汽车二手交易转让门户APP/小程序uniapp

源码地址：ym7k.com/19279/

## 🧱 技术栈

- **前端：UniApp（uView）**，一套代码 → 小程序、H5、APP
- **后端：FastAdmin / ThinkPHP6 + MySQL + Redis**
- **配套：PC 门户官网 + PC 运营总后台**
- **部署环境：PHP7.4–8.1、Nginx、高德 / 腾讯地图、OSS、微信支付、短信**

## 🧩 核心模块（后台自由开关、DIY 新增类目）

✅ **求职招聘模块**
企业 / 个人用工入驻，发布全职、兼职、零工；求职者简历投递、报名；岗位筛选、置顶刷新、隐私聊天；可开启鱼泡式工人名片模式。

✅ **房产租售模块**
二手房、新房、租房、商铺、厂房；多字段：面积、户型、楼层、朝向、装修、租金、中介费；地图找房、预约看房、房源相册。

✅ **汽车二手车模块**
二手车、新车、租车、代驾；品牌、里程、年份、排量、价格、车况、过户信息，支持估价标签。

✅ **二手转让交易**
闲置物品、数码、家具、母婴、宠物；个人发布、议价、自提、线上沟通。

✅ **便民生活板块（可选）**
家政、维修、搬家、顺风车、店铺转让、招商、本地商家、活动、征婚交友。

## 🙋 用户端（APP / 小程序 / H5）

- 微信 / 手机号登录、实名认证、发布权限管控
- LBS 自动定位、切换城市、同城优先、地图信息点位
- **DIY 动态表单**：不同分类独立自定义发布字段，房产一套表单、二手车一套、招聘一套
- 信息浏览、筛选、收藏、私信 IM、脱敏电话、评论、举报
- 发布管理：上架、下架、编辑、刷新、付费置顶 / 加急
- 个人中心：我的发布、收藏、订单、充值、推广海报、消息通知

## 🏪 商家 / 企业端

- 资质审核（营业执照、实名）、商家主页
- 套餐入驻、店铺介绍、相册、本店信息聚合展示
- 独立管理后台，批量发布房源、车源、岗位、服务
- 线索管理：看房预约、简历投递、咨询线索统一汇总

## 🛠️ PC 总运营后台（DIY 核心）

> 
> 这个是这套和单纯招聘源码最大区别：可视化搭建分类

- **自定义分类管理**：无限一级、二级分类；给每个分类单独配置表单字段、上传项、筛选标签（重点 DIY）
- 信息审核、先发后审、敏感词、举报、黑名单
- 多城市分站：分站独立管理员、独立广告、独立定价、分佣
- 变现体系：信息置顶、刷新、加急、会员套餐、商家入驻费、广告位、分销推广佣金
- 财务：充值、订单、流水、提现、对账
- PC 门户网站配置：导航、轮播、首页板块拖拽布局、SEO 标题关键词
- 数据大盘：分类目、分城市发布量、浏览、咨询转化统计
- 权限分级：运营、财务、分站代理、客服子账号

## ✨ 主打特色

1. **DIY 自定义类目表单**，不用改代码，后台新增分类、增减字段；想做招聘门户就主打招聘，想做二手车平台就关闭其余模块，灵活改造。
2. **全品类聚合**：招聘、房产、二手车、二手、便民一体化，本地流量互通。
3. **多端一体**：小程序、H5、APP、PC 门户，适合县城、地级市本地创业。
4. **分销裂变**：分享海报、邀请注册、信息成交分成，适合代理合伙人模式。
5. **插件可拓展**：团购、到店、同城跑腿、同城商圈、招工直播、担保交易。
6. **源码交付私有化部署**，数据自留，无 SaaS 绑定，深度二开。
